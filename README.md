# Portfolio React App

This project is a personal portfolio built with React. It showcases skills, projects, experience with contact option.

## Features

* Built using React with a modular component structure.
* Fully responsive layout optimized for mobile, tablet, and desktop.
* Accessible UI with proper roles, aria attributes, and keyboard-friendly navigation.
* Clean routing structure for sections like Home, About, Skills, Projects, and Contact.
* Lightweight and fast, suitable for deployment on static hosting platforms.

## Tech Stack

* **React**
* **Vite**
* **TailwindCSS**
* **React Router** for navigation

## Folder Structure

```
/src
  /components
  /pages
  /assets
  /hooks
  /utils
  App.jsx
  main.jsx
```

## Installation

```
npm install
npm start
```

## Build

```
npm run build
```
